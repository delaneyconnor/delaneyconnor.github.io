# Delaney Connor - Portfolio

My personal portfolio website built with HTML, CSS, and JavaScript.

## About

This is my portfolio website where I showcase my projects and share information about myself.

## Features

- Responsive design that works on all devices
- Smooth scrolling navigation
- Animated sections
- Clean and modern design

## How to View

Visit: [https://delaneyconnor.github.io](https://delaneyconnor.github.io)

## How to Customize

1. **Update your information**: Edit `index.html` to add your details, bio, and projects
2. **Change colors**: Modify `style.css` to update the color scheme
3. **Add projects**: Add new project cards in the Projects section of `index.html`
4. **Update contact links**: Replace the email and add any other social media links

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
